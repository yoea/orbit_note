# 手动测试清单

> 双平台：iPhone Safari（iOS 26，生产或局域网 HTTPS）+ Windows 11 Edge（开发 localhost）
> 每项记录：✅ 通过 / ❌ 失败 + 现象

## WebAuthn
- [ ] 首次注册（/setup → 创建 Passkey → Face ID/Windows Hello）
- [ ] 登录（/login → 解锁 → 进入首页）
- [ ] 错误 credential（从未注册的浏览器登录）
- [ ] 未认证访问 API（无 session 调 /api/diary → 401）
- [ ] 登录退出（设置页退出 → 回 /login）
- [ ] 多 credential（设置页添加第二个 Passkey → 两个都能解锁）

## E2EE
- [ ] 加密/解密往返（写 → 保存 → 历史可见）
- [ ] 刷新页面（DEK 清空 → 重新 Face ID 解锁）
- [ ] 登出后重新登录（解锁路径正确）
- [ ] 删除浏览器缓存后（数据仍在，重新初始化流程被拒绝 → 只能解锁）
- [ ] 恢复 key 解锁（PRF 不可用设备 → 粘贴 Recovery Key）
- [ ] 错误 recovery key（→ 明确报错）
- [ ] 篡改密文（DB 手动改 ciphertext → 详情页显示解密失败占位，编辑禁用）

## Diary
- [ ] 新建（保存 → 已保存 · 时间）
- [ ] 编辑（详情 → 编辑 → 保存 → 内容更新）
- [ ] 删除（二次确认 → 列表消失）
- [ ] 多行/中文/Emoji（😀 ❤️ 🥹 😭 🫠 😂）
- [ ] 长文本（>1000 字）
- [ ] 空白内容（保存按钮禁用）
- [ ] 断网保存（失败提示，内容保留）
- [ ] 恢复网络（草稿同步）

## Draft
- [ ] 自动保存（输入停顿 1s 后本地+服务器）
- [ ] 刷新后恢复（横幅 → 恢复）
- [ ] 关闭浏览器重开恢复
- [ ] 离线输入（断网继续写 → 本地草稿）
- [ ] 冲突（另一设备保存较新草稿 → 本设备显示横幅，取较新）

## Geolocation
- [ ] 允许定位（保存 → 详情显示坐标）
- [ ] 拒绝定位（保存成功，无位置）
- [ ] 无法获取（飞行模式 → 保存成功）
- [ ] 精度显示（坐标展开 → ±N 米）

- [ ] 图标显示正确
- [ ] 深色模式（设置切深色 → 应用跟随）
